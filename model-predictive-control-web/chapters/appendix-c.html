C.3 Điều Kiện Tối Ưu Karush-Kuhn-Tucker (KKT) Cho Bài Toán Có Ràng Buộc

Xét bài toán tối ưu hóa phi tuyến tổng quát:

$$\min_{x} f(x) \quad \text{s.t.} \quad g_i(x) \le 0 \; (i=1,\dots,m), \quad h_j(x) = 0 \; (j=1,\dots,p)$$

Hàm Lagrange: $\mathcal{L}(x, \lambda, \nu) = f(x) + \sum_{i=1}^m \lambda_i g_i(x) + \sum_{j=1}^p \nu_j h_j(x)$. Điểm $x^*$ là nghiệm tối ưu khi và chỉ khi tồn tại các nhân tử $(\lambda^*, \nu^*)$ thỏa mãn 4 điều kiện KKT:

HỆ ĐIỀU KIỆN TỐI ƯU KKT (KARUSH-KUHN-TUCKER CONDITIONS)
$$\nabla_x \mathcal{L}(x^*, \lambda^*, \nu^*) = 0 \quad (\text{Tính dừng Gradient})$$ $$g_i(x^*) \le 0, \quad h_j(x^*) = 0 \quad (\text{Tính khả thi nguyên thủy})$$ $$\lambda_i^* \ge 0 \quad (\text{Tính khả thi đối ngẫu})$$ $$\lambda_i^* g_i(x^*) = 0 \quad (\text{Độ bù bù trừ - Complementary Slackness})$$
