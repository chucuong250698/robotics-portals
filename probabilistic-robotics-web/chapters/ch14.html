💡 VÌ SAO QUY TRÌNH QUYẾT ĐỊNH MARKOV LÀ CẦU NỐI GIỮA ĐỊNH VỊ VÀ HÀNH ĐỘNG?

Biết vị trí của mình ở đâu mới chỉ là một nửa chặng đường. Câu hỏi tối thượng tiếp theo là: "Bây giờ tôi nên làm gì để đạt được mục tiêu an toàn nhất?".

Trong điều khiển cổ điển (như Dijkstra hay A*), bài toán tìm đường giả định rằng nếu chọn đi sang phải, robot chắc chắn $100\%$ sẽ sang phải. Nhưng trên sàn trơn hoặc dốc cát:

  • Lệnh đi thẳng có thể bị trượt sang trái hoặc phải với xác suất $20\%$.
  • Nếu bên cạnh là một vực sâu nguy hiểm (vách đá/hố rác), một thuật toán hình học ngây thơ sẽ chọn đường đi sát mép vực vì nó "ngắn nhất".
  • Kết quả: Robot bị rơi xuống vực khi gặp cú trượt đầu tiên!

Quá trình quyết định Markov (MDP) và Phương trình tối ưu Bellman giải quyết bài toán này bằng cách cân bằng giữa phần thưởng mục tiêu và chi phí rủi ro ngẫu nhiên, hướng dẫn robot chọn con đường có kỳ vọng an toàn cao nhất trong dài hạn.

14.1 Động Lực: Ra Quyết Định Dưới Bất Định (Motivation)

Một bài toán Markov Decision Process (MDP) được định nghĩa bởi bộ 4 thành phần $\langle \mathcal{S}, \mathcal{A}, \mathcal{T}, \mathcal{R}, \gamma \rangle$:

  • $\mathcal{S}$: Không gian trạng thái rời rạc hoặc liên tục.
  • $\mathcal{A}$: Tập các hành động robot có thể thực hiện.
  • $\mathcal{T}(s, a, s') = p(s' \mid s, a)$: Xác suất chuyển từ trạng thái $s$ sang $s'$ khi thực thi hành động $a$.
  • $\mathcal{R}(s, a, s')$: Hàm phần thưởng tức thời nhận được.
  • $\gamma \in [0, 1)$: Hệ số chiết khấu phần thưởng tương lai (Discount factor).

14.3 Thuật Toán Lặp Giá Trị (Value Iteration)

14.3.3 Phương Trình Tối Ưu Bellman

Hàm giá trị tối ưu $V^*(s)$ đại diện cho tổng phần thưởng chiết khấu kỳ vọng tối đa mà robot có thể nhận được từ trạng thái $s$ đến vô hạn:

$$V^*(s) = \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} p(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^*(s') \right]$$

Thuật toán Value Iteration cập nhật lặp đồng thời trên toàn bộ các trạng thái:

$$V_{k+1}(s) \leftarrow \max_{a} \sum_{s'} p(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V_k(s') \right]$$

Sau khi hàm giá trị hội tụ ($||V_{k+1} - V_k||_\infty \lt \epsilon$), Chính sách điều khiển tối ưu $\pi^*(s)$ được suy ra bằng phép chọn hành động tham lam (Greedy selection):

CHÍNH SÁCH ĐIỀU KHIỂN TỐI ƯU
$$\pi^*(s) = \arg\max_{a \in \mathcal{A}} \sum_{s'} p(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^*(s') \right]$$

Ví Dụ Tính Số 4 Bước: Hai Vòng Lặp Value Iteration Trên Thế Giới 2x2

BƯỚC 1
Khởi Tạo Môi Trường & Phần Thưởng

Thế giới gồm 4 ô: $s_1$ (khởi đầu), $s_2$ (gần hố), $s_3$ (đích đến $+10$), $s_4$ (hố nguy hiểm $-10$).
Chi phí mỗi bước di chuyển: $R = -1.0$. Hệ số chiết khấu: $\gamma = 0.90$.
Xác suất hành động: Khi chọn hành động, có $80\%$ cơ hội đi đúng hướng, $20\%$ cơ hội trượt đứng yên tại chỗ.
Khởi tạo ban đầu: $V_0 = [0, 0, 10, -10]^T$. Ô $s_3, s_4$ là trạng thái kết thúc (Terminal).

BƯỚC 2
Vòng Lặp 1: Cập Nhật Trạng Thái $s_1$

Tại $s_1$:

  • Hành động $a_{\text{right}}$ (đi sang $s_2$): $$Q(s_1, \text{right}) = 0.8 \times [-1.0 + 0.9 \times V_0(s_2)] + 0.2 \times [-1.0 + 0.9 \times V_0(s_1)] = 0.8(-1.0) + 0.2(-1.0) = -1.0$$
  • Hành động $a_{\text{down}}$ (đi sang đích $s_3$): $$Q(s_1, \text{down}) = 0.8 \times [-1.0 + 0.9 \times 10] + 0.2 \times [-1.0 + 0.9 \times 0] = 0.8 \times 8.0 - 0.2 = 6.4 - 0.2 = \mathbf{+6.2}$$
$$\implies V_1(s_1) = \max(-1.0, 6.2) = \mathbf{+6.2}$$

BƯỚC 3
Vòng Lặp 1: Cập Nhật Trạng Thái $s_2$

Tại $s_2$:

  • Hành động $a_{\text{down}}$ (đi xuống hố $s_4$): $$Q(s_2, \text{down}) = 0.8 \times [-1.0 + 0.9 \times (-10)] + 0.2 \times [-1.0] = 0.8(-10.0) - 0.2 = -8.2$$
  • Hành động $a_{\text{left}}$ (quay về $s_1$ an toàn): $$Q(s_2, \text{left}) = 0.8 \times [-1.0 + 0.9 \times V_0(s_1)] + 0.2 \times [-1.0] = -1.0$$
$$\implies V_1(s_2) = \max(-8.2, -1.0) = \mathbf{-1.0}$$ Vector giá trị sau vòng 1: $V_1 = [6.2, -1.0, 10.0, -10.0]^T$.

BƯỚC 4
Vòng Lặp 2 & Quyết Định Chính Sách Tối Ưu

Tại $s_2$ trong vòng lặp 2, hành động $a_{\text{left}}$ tận dụng được giá trị mới của $s_1$: $$Q(s_2, \text{left}) = 0.8 \times [-1.0 + 0.9 \times 6.2] + 0.2 \times [-1.0 + 0.9 \times (-1.0)] = 0.8(4.58) - 0.38 \approx \mathbf{+3.284}$$ $$\implies V_2(s_2) = \mathbf{+3.284}$$ Chính sách tối ưu: $\pi^*(s_1) = \text{Đi Xuống}$ (hướng thẳng về đích $+10$), $\pi^*(s_2) = \text{Đi Sang Trái}$ (tuyệt đối không đi xuống hố nguy hiểm mà lùi lại $s_1$ rồi mới vòng xuống đích).

Cầu Nối Kiến Trúc Thực Chiến: Tích Hợp MDP Vào Nav2 Behavior Tree

ROS 2 AUTONOMOUS DECISION MAKING src/mdp_risk_aware_recovery.cpp

Mã nguồn plugin điều phối phục hồi rủi ro bằng MDP tích hợp vào cây hành vi Nav2: 

#include <behaviortree_cpp_v3/action_node.h>
#include <rclcpp/rclcpp.hpp>

class MdpRiskAwarePlanner : public BT::SyncActionNode {
public:
  MdpRiskAwarePlanner(const std::string& name, const BT::NodeConfiguration& config)
  : BT::SyncActionNode(name, config) {}

  BT::NodeStatus tick() override {
    // Tinh toan chinh sach toi uu pi*(s) bang cach giai nhanh Bellman tren luoi chi phi dia phuong
    Action optimal_action = solveLocalBellmanPolicy();

    if (optimal_action == Action::SAFE_DETOUR) {
      setOutput("chosen_recovery", "spin_and_replan");
      return BT::NodeStatus::SUCCESS;
    } else if (optimal_action == Action::HALT_IMMEDIATELY) {
      return BT::NodeStatus::FAILURE;
    }
    return BT::NodeStatus::SUCCESS;
  }

private:
  Action solveLocalBellmanPolicy() {
    // Giai gia tri Bellman voi he so phan thuong am cho cac vung costmap inflation cao
    return Action::SAFE_DETOUR;
  }
};
