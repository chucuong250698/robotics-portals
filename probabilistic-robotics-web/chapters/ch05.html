Mô Hình Chuyển Động Robot Di Động: Vận Tốc & Odometry

Chuyên khảo Probabilistic Robotics (The MIT Press) — GS. Sebastian Thrun, GS. Wolfram Burgard, GS. Dieter Fox.

💡 VÌ SAO KHÔNG THỂ DÙNG ĐỘNG HỌC HÌNH HỌC THUẦN TÚY CHO ROBOT DI ĐỘNG?

Trong sách giáo khoa cơ học cổ điển, khi gửi lệnh vận tốc dài $v$ và vận tốc góc $\omega$ trong thời gian $\Delta t$, robot di chuyển hoàn hảo trên một cung tròn bán kính $r = v / \omega$.

Trong thế giới thực:

  • Bánh xe bên trái trượt nhiều hơn bên phải $2\%$, robot rẽ lệch quỹ đạo.
  • Gờ sàn nhỏ làm robot nảy nhẹ, sai số góc hướng $\Delta \theta$ lập tức khuếch đại sai số vị trí $(x, y)$ theo thời gian.
  • Chỉ sau 10 mét chạy thẳng, ước lượng hình học thuần túy có thể lệch hàng mét và quay sai hướng $30^\circ$.

Mô hình động học xác suất (Probabilistic Kinematics) giải quyết bài toán này bằng cách mô hình hóa chuyển động như một quá trình ngẫu nhiên: mọi hành động đều làm phát tán và uốn cong đám mây bất định thành phân bố hình quả chuối (Banana-shaped distribution) phản ánh trung thực vật lý của bánh xe.

5.1 Mở Đầu Về Chuyển Động Robot Di Động (Introduction)

Chuyển động của robot di động phẳng được đặc trưng bởi tư thế 3 bậc tự do $x = (x, y, \theta)^T \in \text{SE}(2)$.

5.2 Cơ Sở Động Học Xác Suất (Probabilistic Kinematics)

Mô hình chuyển động xác định mật độ xác suất chuyển tiếp:

XÁC SUẤT CHUYỂN TIẾP TRẠNG THÁI
$$p(x_t \mid u_t, x_{t-1})$$

Thrun, Burgard và Fox phân loại 2 hướng tiếp cận mô hình hóa chuyển động:

  1. Mô hình vận tốc (Velocity Motion Model): Dựa trên lệnh điều khiển $u_t = (v, \omega)^T$ gửi tới động cơ. Dùng cho bài toán lập kế hoạch (planning).
  2. Mô hình Odometry (Odometry Motion Model): Dựa trên dữ liệu cảm biến đo vòng quay bánh xe (wheel encoders). Dùng cho bài toán ước lượng trạng thái và định vị (estimation & localization).

5.3 Mô Hình Chuyển Động Vận Tốc (Velocity Motion Model)

5.3.1 Công Thức Dạng Kín Giải Tích

Giả sử robot di chuyển với vận tốc dài $v$ và vận tốc góc $\omega$ trong khoảng thời gian $\Delta t$. Tâm quay tức thời (Instantaneous Center of Curvature - ICC) có tọa độ:

$$x_c = x - \frac{v}{\omega} \sin\theta, \quad y_c = y + \frac{v}{\omega} \cos\theta$$

Để giải quyết nhiễu thực tế, mô hình đưa vào 4 tham số sai số động học $\alpha_1, \alpha_2, \alpha_3, \alpha_4$:

$$\hat{v} = v + \epsilon(\alpha_1 v^2 + \alpha_2 \omega^2)$$ $$\hat{\omega} = \omega + \epsilon(\alpha_3 v^2 + \alpha_4 \omega^2)$$ $$\hat{\gamma} = \epsilon(\alpha_5 v^2 + \alpha_6 \omega^2) \quad \text{(Góc hướng cuối cùng)}$$

5.4 Mô Hình Chuyển Động Odometry (Odometry Motion Model)

5.4.1 Phân Rã 3 Bước: Quay $\to$ Tịnh Tiến $\to$ Quay

Cảm biến odometry cung cấp tư thế ước tính của bánh xe $\bar{x}_{t-1} = (\bar{x}, \bar{y}, \bar{\theta})^T$ và $\bar{x}_t = (\bar{x}', \bar{y}', \bar{\theta}')^T$. Bất kỳ chuyển động phẳng nào giữa hai thời điểm đều được phân rã chính xác thành:

BA BƯỚC PHÂN RÃ CHUYỂN ĐỘNG ODOMETRY
$$\delta_{\text{rot1}} = \text{atan2}(\bar{y}' - \bar{y}, \bar{x}' - \bar{x}) - \bar{\theta}$$ $$\delta_{\text{trans}} = \sqrt{(\bar{x}' - \bar{x})^2 + (\bar{y}' - \bar{y})^2}$$ $$\delta_{\text{rot2}} = \bar{\theta}' - \bar{\theta} - \delta_{\text{rot1}}$$

5.4.2 Thuật Toán Lấy Mẫu Hạt Odometry

Khi phát tán các hạt trong bộ lọc Particle Filter, mỗi hạt $x_{t-1}^{[m]} = (x, y, \theta)^T$ được cập nhật theo:

$$\hat{\delta}_{\text{rot1}} = \delta_{\text{rot1}} - \text{sample}(\alpha_1 \delta_{\text{rot1}}^2 + \alpha_2 \delta_{\text{trans}}^2)$$ $$\hat{\delta}_{\text{trans}} = \delta_{\text{trans}} - \text{sample}(\alpha_3 \delta_{\text{trans}}^2 + \alpha_4 \delta_{\text{rot1}}^2 + \alpha_4 \delta_{\text{rot2}}^2)$$ $$\hat{\delta}_{\text{rot2}} = \delta_{\text{rot2}} - \text{sample}(\alpha_1 \delta_{\text{rot2}}^2 + \alpha_2 \delta_{\text{trans}}^2)$$ $$x' = x + \hat{\delta}_{\text{trans}} \cos(\theta + \hat{\delta}_{\text{rot1}})$$ $$y' = y + \hat{\delta}_{\text{trans}} \sin(\theta + \hat{\delta}_{\text{rot1}})$$ $$\theta' = \theta + \hat{\delta}_{\text{rot1}} + \hat{\delta}_{\text{rot2}}$$

Ví Dụ Tính Số 4 Bước: Phân Rã Chuyển Động Odometry & Lấy Mẫu

BƯỚC 1
Dữ Liệu Đo Odometry Đầu Vào

Tư thế odometry trước: $\bar{x}_{t-1} = (2.0\text{ m}, 3.0\text{ m}, 0.0\text{ rad})^T$.
Tư thế odometry sau: $\bar{x}_t = (4.0\text{ m}, 5.0\text{ m}, \pi/4\text{ rad})^T$.
Các tham số nhiễu: $\alpha_1 = 0.05$, $\alpha_2 = 0.01$, $\alpha_3 = 0.05$, $\alpha_4 = 0.01$.

BƯỚC 2
Tính 3 Đại Lượng Động Học Phân Rã

Độ dời vị trí: $\Delta x = 4.0 - 2.0 = 2.0$ m; $\Delta y = 5.0 - 3.0 = 2.0$ m.
Khoảng cách tịnh tiến: $$\delta_{\text{trans}} = \sqrt{2.0^2 + 2.0^2} = \sqrt{8} \approx \mathbf{2.8284\text{ m}}$$ Góc quay bước 1: $$\delta_{\text{rot1}} = \text{atan2}(2.0, 2.0) - 0.0 = \frac{\pi}{4} \approx \mathbf{0.7854\text{ rad}} \quad (45^\circ)$$ Góc quay bước 2: $$\delta_{\text{rot2}} = \frac{\pi}{4} - 0.0 - \frac{\pi}{4} = \mathbf{0.0\text{ rad}}$$

BƯỚC 3
Tính Phương Sai Nhiễu & Gieo Mẫu Hạt

Phương sai tịnh tiến: $$\sigma_{\text{trans}}^2 = \alpha_3 \delta_{\text{trans}}^2 + \alpha_4 (\delta_{\text{rot1}}^2 + \delta_{\text{rot2}}^2) = 0.05 \times 8 + 0.01 \times (0.7854^2 + 0) = 0.406\text{ m}^2$$ $\implies \sigma_{\text{trans}} \approx 0.637$ m.
Phương sai quay 1: $$\sigma_{\text{rot1}}^2 = \alpha_1 \delta_{\text{rot1}}^2 + \alpha_2 \delta_{\text{trans}}^2 = 0.05 \times 0.617 + 0.01 \times 8 = 0.111 \implies \sigma_{\text{rot1}} \approx 0.333\text{ rad}$$ Giả sử rút mẫu ngẫu nhiên: $\epsilon_{\text{trans}} = +0.10$ m, $\epsilon_{\text{rot1}} = -0.05$ rad, $\epsilon_{\text{rot2}} = +0.02$ rad.

BƯỚC 4
Tư Thế Hạt Sau Khi Chuyển Động

Giả sử hạt bắt đầu từ $x = (2.1, 2.9, 0.05)^T$: $$\hat{\delta}_{\text{trans}} = 2.8284 + 0.10 = 2.9284\text{ m}$$ $$\hat{\delta}_{\text{rot1}} = 0.7854 - 0.05 = 0.7354\text{ rad}$$ $$x' = 2.1 + 2.9284 \times \cos(0.05 + 0.7354) \approx \mathbf{4.17\text{ m}}$$ $$y' = 2.9 + 2.9284 \times \sin(0.05 + 0.7354) \approx \mathbf{4.97\text{ m}}$$ $$\theta' = 0.05 + 0.7354 + 0.02 \approx \mathbf{0.805\text{ rad}} \quad (46.1^\circ)$$

Cầu Nối Kiến Trúc Thực Chiến: Node Phát Tán Odometry & Cây TF Trong ROS 2

ROS 2 NAVIGATION TRANSFORM & ODOMETRY src/diff_drive_odometry_publisher.cpp

Quy ước cấu trúc cây tọa độ tiêu chuẩn trong ROS 2 Nav2: map -> odom -> base_footprint -> base_link. Node odometry chịu trách nhiệm tính toán tích phân góc và xuất bản cả topic lẫn broadcast TF: 

#include <rclcpp/rclcpp.hpp>
#include <nav_msgs/msg/odometry.hpp>
#include <tf2_ros/transform_broadcaster.h>
#include <geometry_msgs/msg/transform_stamped.hpp>

class OdometryPublisher : public rclcpp::Node {
public:
  OdometryPublisher() : Node("odometry_publisher") {
    odom_pub_ = create_publisher<nav_msgs::msg::Odometry>("odom", 50);
    tf_broadcaster_ = std::make_unique<tf2_ros::TransformBroadcaster>(*this);
  }

  void updateOdometry(double dt, double v, double w) {
    // Tich phan vi tri Runge-Kutta 2
    double delta_theta = w * dt;
    double delta_x = v * std::cos(theta_ + delta_theta / 2.0) * dt;
    double delta_y = v * std::sin(theta_ + delta_theta / 2.0) * dt;

    x_ += delta_x;
    y_ += delta_y;
    theta_ += delta_theta;

    // 1. Broadcast TF: odom -> base_footprint
    geometry_msgs::msg::TransformStamped tf_msg;
    tf_msg.header.stamp = now();
    tf_msg.header.frame_id = "odom";
    tf_msg.child_frame_id = "base_footprint";
    tf_msg.transform.translation.x = x_;
    tf_msg.transform.translation.y = y_;
    tf_msg.transform.translation.z = 0.0;
    tf_msg.transform.rotation.z = std::sin(theta_ / 2.0);
    tf_msg.transform.rotation.w = std::cos(theta_ / 2.0);
    tf_broadcaster_->sendTransform(tf_msg);

    // 2. Publish nav_msgs/msg/Odometry
    nav_msgs::msg::Odometry odom;
    odom.header = tf_msg.header;
    odom.child_frame_id = "base_footprint";
    odom.pose.pose.position.x = x_;
    odom.pose.pose.position.y = y_;
    odom.twist.twist.linear.x = v;
    odom.twist.twist.angular.z = w;
    odom_pub_->publish(odom);
  }

private:
  double x_ = 0.0, y_ = 0.0, theta_ = 0.0;
  rclcpp::Publisher<nav_msgs::msg::Odometry>::SharedPtr odom_pub_;
  std::unique_ptr<tf2_ros::TransformBroadcaster> tf_broadcaster_;
};
