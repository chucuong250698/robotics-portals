Chương 05: Ước Lượng Phi Tuyến: EKF, IEKF, UKF & Particle Filter

Chuyên khảo học thuật chuyên sâu: Bóc tách nền tảng toán học, bài tập kỹ thuật có lời giải chi tiết, mô phỏng trực quan tương tác 60 FPS và cầu nối hệ thống robot thực tế.

⏱️ Thời lượng đọc: 35 phút 📚 Nguồn sách gốc: Prof. Timothy Barfoot (2nd Ed), Mục 4.1–4.4 (Trang 103–142) 🎯 Trọng tâm: Tuyến tính hóa Taylor, Biến đổi Unscented & Phân phối đa đỉnh với Hạt

1. Động Cơ Kỹ Thuật: Tại Sao Phải Cần Khái Niệm Này?

💡 Ý nghĩa thực tế: Để làm gì?

Thế giới thực tế của robot hoàn toàn phi tuyến: camera chiếu phối cảnh qua phép chia phối cảnh $1/Z$, cảm biến LiDAR đo khoảng cách theo hàm căn bậc hai $\sqrt{x^2+y^2}$, góc quay Euler xoay vòng lượng giác $\sin, \cos$. Bộ lọc Kalman tuyến tính sẽ thất bại thảm hại! EKF, UKF và Particle Filter là 3 trụ cột kỹ thuật giúp robot thuần hóa các bài toán phi tuyến phức tạp trong thế giới thực.

Nếu EKF dùng khai triển chuỗi Taylor bậc 1 (cắt bỏ phần dư bậc cao, dễ phân kỳ khi độ phi tuyến lớn), thì UKF áp dụng phương châm: 'Xấp xỉ một phân phối xác suất dễ hơn nhiều so với xấp xỉ một hàm phi tuyến'. Bằng cách chọn $2n+1$ điểm mẫu xác định (Sigma Points), UKF nắm bắt chính xác kỳ vọng và phương sai đến cấp độ Taylor bậc 3 mà không cần tính đạo hàm giải tích Jacobian!

2. Lý Thuyết Nền Tảng & Hệ Thống Phương Trình Cốt Lõi

Xét hệ thống phi tuyến tổng quát:

$$\begin{align} \mathbf{x}_k &= \mathbf{f}(\mathbf{x}_{k-1}, \mathbf{u}_{k-1}) + \mathbf{w}_k \\ \mathbf{y}_k &= \mathbf{h}(\mathbf{x}_k) + \mathbf{n}_k \end{align}$$

1. Extended Kalman Filter (EKF): Tuyến tính hóa Taylor bậc 1 quanh ước lượng gần nhất:

$$\begin{equation} \mathbf{F}_{k-1} = \left. \frac{\partial \mathbf{f}}{\partial \mathbf{x}} \right|_{\hat{\mathbf{x}}_{k-1}}, \qquad \mathbf{H}_k = \left. \frac{\partial \mathbf{h}}{\partial \mathbf{x}} \right|_{\check{\mathbf{x}}_k} \end{equation}$$

2. Iterated EKF (IEKF): Khi hàm đo $\mathbf{h}(\mathbf{x})$ phi tuyến mạnh, IEKF chạy vòng lặp Gauss-Newton ngay tại bước Update để tìm điểm tuyến tính hóa tốt hơn $\hat{\mathbf{x}}_k^{(i+1)}$ thay vì dùng cố định $\check{\mathbf{x}}_k$.

3. Giải Phẫu Toán Học & Phân Tích Thuật Toán

Phép Biến Đổi Unscented (Unscented Transform - UT)
$$\begin{align} \boldsymbol{\mathcal{X}}_0 &= \hat{\mathbf{x}} \\ \boldsymbol{\mathcal{X}}_i &= \hat{\mathbf{x}} + \left(\sqrt{(n + \lambda)\mathbf{P}}\right)_i, \quad i = 1, \dots, n \\ \boldsymbol{\mathcal{X}}_{i+n} &= \hat{\mathbf{x}} - \left(\sqrt{(n + \lambda)\mathbf{P}}\right)_i, \quad i = 1, \dots, n \end{align}$$

Với $n$ là số chiều trạng thái, UT sinh ra chính xác $2n+1$ điểm Sigma Points. Mỗi điểm được truyền qua hàm phi tuyến thực sự $\boldsymbol{\mathcal{Y}}_i = \mathbf{h}(\boldsymbol{\mathcal{X}}_i)$, sau đó tái tổng hợp lại kỳ vọng và hiệp phương sai theo trọng số $W_i^{(m)}, W_i^{(c)}$.

Particle Filter (Lọc hạt): Khi phân phối có nhiều đỉnh (Multi-modal) - ví dụ robot bị 'bắt cóc' không biết mình đang ở phòng nào - phân phối được biểu diễn bằng một đàn $N_p$ hạt có trọng số $\{ \mathbf{x}^{(i)}, w^{(i)} \}_{i=1}^{N_p}$. Chu trình gồm: Lấy mẫu quan trọng (Importance Sampling) $\to$ Đánh giá trọng số $\to$ Tái lấy mẫu (Resampling) để triệt tiêu các hạt suy biến.

4. Bài Tập Ví Dụ Chuyên Sâu & Các Bước Giải Chi Tiết

🎯 Bài Tập Trọng Tâm Ứng Dụng Robot Thực Tế
Chuẩn 4 Bước Vàng

Ước Lượng Vị Trí Bằng EKF Với Cảm Biến Đo Góc Phương Vị Phi Tuyến

Đề bài kỹ thuật: Robot hoạt động tại tọa độ tiên nghiệm $\check{\mathbf{x}} = [p_x, p_y]^T = [2.0, 2.0]^T\text{ m}$ với hiệp phương sai $\check{P} = \begin{bmatrix} 0.25 & 0.0 \\ 0.0 & 0.25 \end{bmatrix}\text{ m}^2$. Robot quan sát một cột mốc đã biết vị trí tại $\mathbf{m} = [10.0, 10.0]^T\text{ m}$. Cảm biến đo góc phương vị ngắm mốc: $h(\mathbf{x}) = \arctan\left(\frac{m_y - p_y}{m_x - p_x}\right)$. Cảm biến trả về góc đo được $\theta_{meas} = 0.820\text{ rad}$. Phương sai nhiễu đo góc $R = (0.02\text{ rad})^2 = 0.0004\text{ rad}^2$. Yêu cầu: Hãy tính toán ma trận Jacobian đo $H$, hệ số Kalman Gain $K$ và ước lượng vị trí cập nhật $\hat{\mathbf{x}}$ của EKF.
1 Bước 1: Mô hình hóa bài toán & Thiết lập dữ liệu tham số

Xác định khoảng cách tương đối giữa mốc và vị trí tiên nghiệm:
• $\Delta x = m_x - p_x = 10.0 - 2.0 = 8.0\text{ m}$
• $\Delta y = m_y - p_y = 10.0 - 2.0 = 8.0\text{ m}$
• Khoảng cách bình phương $d^2 = \Delta x^2 + \Delta y^2 = 64 + 64 = 128\text{ m}^2$.
Góc dự đoán tiên nghiệm: $\check{\theta} = \arctan(8/8) = \arctan(1) = \pi/4 \approx 0.7854\text{ rad}$.

2 Bước 2: Dẫn xuất ma trận & Tính toán đại số trung gian

Tính ma trận Jacobian đo phi tuyến $H = \left.\frac{\partial h}{\partial \mathbf{x}}\right|_{\check{\mathbf{x}}}$:
Đạo hàm của hàm $\arctan(u)$:
$$\frac{\partial h}{\partial p_x} = \frac{1}{1 + (\Delta y / \Delta x)^2} \frac{\partial (\Delta y / \Delta x)}{\partial p_x} = \frac{\Delta x^2}{\Delta x^2 + \Delta y^2} \left( \frac{\Delta y}{\Delta x^2} \right) = \frac{\Delta y}{d^2} = \frac{8.0}{128} = +0.0625\text{ rad/m}$$
$$\frac{\partial h}{\partial p_y} = \frac{1}{1 + (\Delta y / \Delta x)^2} \left( -\frac{1}{\Delta x} \right) = -\frac{\Delta x}{d^2} = -\frac{8.0}{128} = -0.0625\text{ rad/m}$$
Do đó: $H = [0.0625, -0.0625]\text{ rad/m}$.

3 Bước 3: Ráp số vào công thức & Tính toán ra đáp số cuối cùng

Tính Innovation, Kalman Gain và cập nhật trạng thái:
• Phần dư đo: $\nu = \theta_{meas} - \check{\theta} = 0.8200 - 0.7854 = +0.0346\text{ rad}$.
• Hiệp phương sai phần dư:
$$S = H \check{P} H^T + R = [0.0625, -0.0625] \begin{bmatrix} 0.25 & 0 \\ 0 & 0.25 \end{bmatrix} \begin{bmatrix} 0.0625 \\ -0.0625 \end{bmatrix} + 0.0004 = 0.25(0.0625^2 + 0.0625^2) + 0.0004 = 0.001953 + 0.0004 = 0.002353\text{ rad}^2$$
• Kalman Gain:
$$K = \check{P} H^T S^{-1} = \begin{bmatrix} 0.25 \times 0.0625 \\ 0.25 \times (-0.0625) \end{bmatrix} \frac{1}{0.002353} = \begin{bmatrix} 0.015625 \\ -0.015625 \end{bmatrix} \times 424.99 = \begin{bmatrix} +6.640 \\ -6.640 \end{bmatrix}$$
• Cập nhật trạng thái:
$$\hat{\mathbf{x}} = \check{\mathbf{x}} + K \nu = \begin{bmatrix} 2.0 \\ 2.0 \end{bmatrix} + \begin{bmatrix} +6.640 \\ -6.640 \end{bmatrix} \times 0.0346 = \begin{bmatrix} 2.0 + 0.230 \\ 2.0 - 0.230 \end{bmatrix} = \begin{bmatrix} 2.230\text{ m} \\ 1.770\text{ m} \end{bmatrix}$$

4 Bước 4: Diễn giải ý nghĩa vật lý, kiểm tra độ nhạy & Phân tích kỹ thuật

Diễn giải hình học: Cảm biến đo được góc lớn hơn dự đoán ($0.820 \gt 0.7854\text{ rad}$). Để góc phương vị nhìn mốc tăng lên, robot phải dịch chuyển sang phải theo trục X ($+0.230\text{ m}$) và lùi xuống theo trục Y ($-0.230\text{ m}$), vuông góc với tia ngắm mốc! EKF đã tự động giải bài toán hình học phi tuyến này một cách tự nhiên.

6. Cầu Nối Kiến Trúc Code C++ / ROS 2

Đoạn mã C++20 công nghiệp minh họa thuật toán lõi của chương, sẵn sàng tích hợp vào ROS 2 Nodes và các bộ giải chuyên dụng:

// Unscented Transform Sigma Points Generator in C++ Eigen
#include <iostream>
#include <vector>
#include <Eigen/Dense>

struct UKFSigmaPoints {
    std::vector<Eigen::Vector2d> points;
    std::vector<double> Wm;
    std::vector<double> Wc;
};

UKFSigmaPoints generateSigmaPoints(
    const Eigen::Vector2d& x,
    const Eigen::Matrix2d& P,
    double alpha = 1e-3,
    double beta = 2.0,
    double kappa = 0.0) 
{
    int n = x.size();
    double lambda = alpha * alpha * (n + kappa) - n;
    double gamma = std::sqrt(n + lambda);
    
    // Matrix square root via Cholesky decomposition
    Eigen::LLT<Eigen::Matrix2d> llt(P);
    Eigen::Matrix2d L = llt.matrixL();
    
    UKFSigmaPoints sp;
    sp.points.resize(2 * n + 1);
    sp.Wm.resize(2 * n + 1);
    sp.Wc.resize(2 * n + 1);
    
    // Center point
    sp.points[0] = x;
    sp.Wm[0] = lambda / (n + lambda);
    sp.Wc[0] = sp.Wm[0] + (1.0 - alpha * alpha + beta);
    
    // 2n symmetric points
    for (int i = 0; i < n; ++i) {
        sp.points[i + 1] = x + gamma * L.col(i);
        sp.points[i + 1 + n] = x - gamma * L.col(i);
        sp.Wm[i + 1] = sp.Wm[i + 1 + n] = 0.5 / (n + lambda);
        sp.Wc[i + 1] = sp.Wc[i + 1 + n] = sp.Wm[i + 1];
    }
    return sp;
}

int main() {
    Eigen::Vector2d x(2.0, 2.0);
    Eigen::Matrix2d P = 0.25 * Eigen::Matrix2d::Identity();
    auto sp = generateSigmaPoints(x, P);
    std::cout << "Generated " << sp.points.size() << " UKF Sigma Points successfully!\n";
    std::cout << "Center Point: " << sp.points[0].transpose() << "\n";
    return 0;
}

7. Tổng Kết & Bài Học Cốt Lõi

  • EKF: Nhanh, phổ biến, nhưng dễ chệch và phân kỳ khi hệ thống có độ phi tuyến cao hoặc điểm khởi tạo ở xa.
  • IEKF: Giải quyết bài toán phi tuyến đo đạc bằng vòng lặp Gauss-Newton ngay trong bước Update.
  • UKF: Bắt trọn mômen bậc 3 mà không cần tính đạo hàm Jacobian, lựa chọn số 1 cho các bài toán phi tuyến phức tạp.
  • Particle Filter: Giải pháp duy nhất giải quyết triệt để phân phối đa đỉnh và bài toán toàn cục Kidnapped Robot Problem.
